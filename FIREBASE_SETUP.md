# Firebase Setup — Required Steps

## 1. Download google-services.json
- Firebase Console → Project Settings → Your apps → QuantisTradingApp (Android)
- Click "google-services.json" download button
- Place the file at: QuantisApp/google-services.json (root of project)

## 2. This file is already in .gitignore for security
## 3. The app will work without it in JS-only mode (no native Google Sign-In)
## 4. For full Google Sign-In on device, google-services.json is required
